# QAOA Parameter Setting

This repository is for the QAOA parameter setting Q. Opt. working group project.
In this project we investigate the perfromance of various QAOA parameter setting strategies.
The repository has the following structure

* The `methods` folder defines the JSON methods of the parameter setting strategies for the QAOA training pipeline
* The `instances` folder defines the problem instances to work one. These are often specified as graphs.
* The `data` folder includes the results from training and possibly hardware runs.
